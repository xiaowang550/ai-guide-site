## 八个小芽状态

用户原图按尺寸和格式压缩为 384×384 WebP，没有改画角色。八张共 55,458 字节，按状态加载，不在首页一次性下载全部。

| 原图  | 状态     | 触发场景                                   |
| ----- | -------- | ------------------------------------------ |
| 小芽1 | welcome  | 默认欢迎、首次介绍                         |
| 小芽2 | flying   | 查找输入、站内查找、拖动                   |
| 小芽3 | reading  | 教程/知识页、提示词实验                    |
| 小芽4 | guiding  | 安静的周期提示                             |
| 小芽5 | confused | 未找到资料、生成失败                       |
| 小芽6 | working  | 模型回答与实验处理中                       |
| 小芽7 | success  | 回答完成、查找命中、复制成功（4 秒后恢复） |
| 小芽8 | resting  | 无操作超过 1 分钟                          |

状态优先级防止欢迎/休息覆盖处理中或错误；跟随指针只在近距离内轻微移动。CSS 提供飞行、思考、庆祝等幅度有限的动画；减少动态效果偏好会禁用。首次介绍和 4 分钟提示只浮现短文，依旧只有用户点击/轻触才打开聊天。保留手机拖动、边缘限制、位置保存与触摸防双击逻辑。

站内查找会等待资料加载完成再允许发送，Enter 同样遵守这个条件；加载期间保留输入，失败后显示重试入口并切换疑惑形象。资料成功加载后，关闭/重开面板会复用已有资料。已在浏览器中模拟慢加载和失败，验证输入保留与重试恢复。

性能检查：首屏 gzip 增幅约 0.5%–2.1%，通过既有 5% 门禁，没有重置基线。完整工具长文本仍只进入决策器专属块，不进入全站共享块。
