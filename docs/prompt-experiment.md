# 提示词实验

2026-10-15。实验使用通过本站回答测试的具体免费模型，两份请求保持同一模型、推理设置，各自只提交对应问法，不带聊天历史或站内检索资料。实验的模型与推理选择独立于普通聊天；不使用随机路由，不把审核分类器当作写作助手。

原因参考官方说明：[Free Models Router](https://openrouter.ai/openrouter/free) 随机分配免费模型；[Nemotron Content Safety](https://openrouter.ai/nvidia/nemotron-3.5-content-safety) 用于内容审核分类。连接测试通过不代表随机路由的每次下游选择都适合任务。

每份结果独立显示等待、生成、成功或失败；可以只生成或重试其中一份，一份失败后仍尝试另一份，主动停止则不再发下一份请求。修改问法清除对应旧结果；更换模型或推理设置清除整个对比。审核标签与空答由接口及客户端检测为失败，不作为完成结果展示和复制。不自动重试消耗额度，也不伪造“优化前后”的固定答案或评分。

通知示例引导读者观察：信息不足时是否询问必要条件，条件明确时是否保留时间、地点和准备事项。使用者可编辑成其他任务。模型仍可能遗漏要求，需结合实际材料核对。

验证：接口回归测试覆盖随机路由拒绝、单请求上下文隔离、分类输出失败和客户端兼容旧服务；浏览器模拟覆盖三套模板的桌面/手机以及 WebKit 窄屏，检查异常、单份重试、编辑失效、复制、取消及聊天偏好隔离。线上真实生成另行核验，不以模拟结果替代模型效果测试。
