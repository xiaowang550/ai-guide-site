# 练习对话与按基础分流

2026-10-15。

修复练习模式附加“站内公开资料：[]”造成的回答范围误判。练习不注入站内检索内容；一般问题允许运用模型知识回答，站内问答的检索片段仅作参考，不作为普通问题的知识白名单。保留不伪称联网或执行操作的要求。

四个任务入口分别为直接问 AI、写消息、整理待办、读懂一段话。已有原文继续按材料整理；明确的第一人称请求（如“你好，请给我一份北京旅游的攻略”）即使填在读材料里，也按开放式问题处理。普通“请在周五下班前提交……”通知仍按原文处理。用户可以主动切换入口。

真实回答后可以继续追问，携带最近三轮上下文。修改材料、换任务或换模型会清除旧的对话上下文。追问失败且没有新正文时保留上一份回答。教学示例始终明确标记，AI 未连接时不暗中以示例替代生成结果。默认练习模型按每日回答测试记录的首字延迟选取。

首次练习完成后选择基础：零基础带着材料和回答进入 `/start/` 的改要求练习；有基础回首页，显示可收起、可关闭的操作提示，可实际勾选工具打开对比，或填写任务搜索案例。各入口遵守现有模块开关，保留模板预览参数，不新增账户要求。

本地自动化：提示词回归、普通通知与请求区分、存储兼容。浏览器验证使用标明的模拟模型，覆盖三套模板、桌面和手机，以及 WebKit 320px 下的两种身份、两次连续追问、练习结果交接与刷新恢复、比较选择和案例搜索。生产真实模型验证另存 QA 报告，不用模拟输出代替线上结果。
