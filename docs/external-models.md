# 模型接入测试

入口：管理员后台 → 模型接入测试。站点设置中的助手配置也保留同一入口。

填写 OpenAI 兼容 API URL 和 Key，点击“发现并检测全部模型”。服务端读取 `/models`，随后逐个使用 `/chat/completions` 做真实中文回答测试；请求完成、包含预期答案且不是审核标签才通过。支持标准 SSE，以及忽略 `stream:true` 而返回普通 JSON 的兼容接口。审核、向量与部分语音专用模型归入不可用；测试失败保留原因与日期。

通过的模型先留在“可用”，点击“添加到两端”才进入共享助手目录。网页端、教师端和一对一使用同一目录；同源标签页通过时间戳通知更新，切回页面、重新打开助手或轮询也会刷新。新增模型不能绕过回答测试直接发布。模型真实性及费用无法通过连接测试证明，第三方来源在选择器中单独标明。

“停止测试”取消前端当前请求，并将运行中的检测恢复到待检测，保留已经完成的结果；继续时只处理待检测项。已经送达服务商的请求能否立即取消取决于服务商，旧请求晚到的结果不能覆盖暂停、删除或新的检测。单个模型可复测、改名、下架、删除；支持搜索、批量删除失败项及恢复已删除项。删除使用持久记录，重新扫描不会自动恢复；主动恢复的模型必须重新检测、添加。

连接可修改 URL、Key 和名称；改地址必须重填 Key。保存连接或重新发现目录会使旧测试失效，避免把旧 Key 的通过记录用于新 Key。移除连接会同步下架其全部模型。一次目录最多256个模型，最多保存12个连接；过大或非兼容目录明确报错，不截取后冒充完整结果。

每天北京时间08:40，已有模型维护工作流复测已保存且未暂停的外部连接。已经添加的模型通过后继续开放，失败即从共享目录撤下；新发现的模型不会自动发布。测试结果有效36小时，过期自动停止公开调用。暂停的连接需管理员主动继续；删除记录在每日发现中同样保留。每日身份无发布、删除、修改地址及 Key 的权限。

Key 使用服务端 AES-GCM 加密，绑定连接 ID 和规范化 URL，不返回前端、不写日志或测试产物。仅允许所有者管理，写请求检查同源。只支持公网 HTTPS，拒绝 IP/内网/保留地址、本站地址、URL 凭据和查询参数；每次发送凭据前验证 DNS A/AAAA，所有携带 Key 的请求禁止跟随重定向。错误不转发服务商原文；模型测试不保存用户材料或完整生成内容。自定义连接不会替代或复用 OpenRouter/OpenCode 的 Key。

用户提供的 [LMSpeed 页面](https://lmspeed.net/zh/free-api-keys)是社区接口资源目录，不能将其中“可用”标签视作本站测试结果。截图里的 Key 不会自动导入；由所有者在新入口填写实际要使用的连接。

验证：通过真实后台路由与 SQLite 测试权限、加密、发现→实测→添加门禁、两端共用目录、SSE/JSON、失败分类、暂停/删除的并发结果、重命名、持久删除及恢复、Key/URL变更、过期和每日维护权限。浏览器使用模拟接口覆盖三套设计的桌面/手机，验证管理流程及已打开的网页端、教师端同步。此验证不代表对任意第三方 Key 的可用性背书。
