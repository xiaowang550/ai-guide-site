# 双向侧栏滚动

2026-10-13：工具库右侧栏高于屏幕可用高度，原来的固定顶部停靠使底部决策器入口长期处于屏幕外。

`ScrollSidebar` 保留原有侧栏元素、内容与响应式布局。CSS 的 sticky 规则决定哪些断点启用跟随；启用后使用相对位移保留原列的占位，并按父容器底边限制移动，避免 WebKit 在滚动中更改 sticky inset 时的位置更新延迟：

- 侧栏能完整放下时，固定在实际顶栏下方，保留 16px 间距。
- 侧栏较长时，向下随页面逐步露出下方内容，底部进入可见区域后停靠。
- 反向向上滚动立即逐步恢复上方内容，到顶部边界后停靠，避免突然跳动。
- 不添加独立滚动条，不拦截滚轮。到父容器末尾时离开停靠，不覆盖后续内容。
- 窗口、顶栏、内容高度变化时重新测量；适配重新加载及恢复滚动位置。可见的手机底栏从可用高度中扣除。
- 键盘焦点进入侧栏内的控件时调整停靠范围。响应式布局使用 static 时自动退出控制。

复用到工具库、知识库总览、资讯、海外工具访问说明、工具与教程详情、知识文章、案例详情、学校课程与教案详情、新手学习步骤导航。资讯桌面侧栏的后置 static 样式另行修正，让桌面跟随规则生效。

验证包含四个边界单元测试；Chrome、Edge、Firefox、WebKit 的 60 个页面场景检查，包括下滑底边停靠、继续下滑保持、上滑逐步恢复、窗口变化、页面中段决策器入口可见、手机正常流式布局及学校资源。构建、类型、lint、客户端数据审计与原性能预算通过。
