# 回答阅读视图

2026-10-15。新手弹窗、一对一、助手对话/提示词实验、案例练习使用同一套阅读样式。回答默认显示为段落、适度的小标题、列表、表格和代码；需要修改时再点“编辑文字”。编辑框随内容增高，长回答完成后从开头阅读，表格和代码只在必要时左右滑动。

阅读视图通过 react-markdown 与 remark-gfm 渲染，解析器在回答展示时按需加载。禁止原始 HTML、自动图片和危险协议，普通链接由使用者主动打开。代码中的星号、竖线和换行保持原样。复制从渲染后的结构提取文字，保留列表编号、代码、链接目标和表格列，不把排版符号复制进普通段落；原始内容仍用于编辑、对话历史和本地学习进度。

共享系统提示词要求自然、简短，省略套话、自我介绍、装饰表情、重复总结和不必要的表格，尊重使用者明确指定的格式。

验证包括真实组件渲染的语义结构、安全协议/HTML/图片处理与流式未闭合代码；浏览器模拟回答覆盖三套模板的桌面/手机和 WebKit 320px，检查阅读/编辑切换、复制、横向表格、原始用户消息、进度交接及案例草稿修改。生产生成与展示另作线上验证，不把浏览器模拟当成模型效果测试。
