# 弦域 XIAN · 交互与材质更新

2026-10-30。继续保留 XIAN 品牌，依据站主的新反馈增强空间感、明显动效和可操作内容。研究来源及浏览限制见 [设计参考](./xian-refinement-research.md)。所有视觉与代码均为本项目原创，未复制付费模板。

## 本次变化

- X-01 是原生 Canvas 绘制的 2.5D 领航员，拥有金属明暗、玻璃面罩、目光跟随、点击致意，以及待命／专注／跃迁三种姿态。静态 SVG 头像同时用于站内助手。支持键盘操作、暂停和减少动态效果；离屏及隐藏标签页停止循环，尺寸变化仍保留一帧。
- 首页增加三个互动演示：消息、会议记录、待办网页。材料、要求和结果分步查看；网页示例可以实际勾选任务。演示明确标为示例，选择“亲自试试”后带入真实工作台，不自动提交。
- 工作台增加场景示例、分场景草稿、字数、Ctrl/Cmd+Enter、真实任务状态、原需求对照、重试和最近三次任务。最近任务仅保存在当前页面内存；查看旧结果不覆盖当前输入。输出只在阅读位置靠近底部时跟随更新。
- 浮动导航、进度细线、金属与纸面材质、立体卡片反馈、错落案例及滚动进入效果形成不同章节节奏。没有开场等待、滚动劫持、自动音频或虚构指标。
- 导航遵守后台排序、隐藏、改名和自定义栏目；首页重排后按实际位置确定当前章节。区块被删除、隐藏或自定义替换时，不保留无效的工作台入口。

## 性能与验证

角色、演示和工作台拆分为按需组件。工作台延迟加载期间，选中的材料和模式保存在首页状态，完成加载后再交接。角色及工作台样式仅随首页加载；无新增第三方依赖、视频和外部字体。服务工作线程更新为 v10。

首屏 gzip 测量约 195.9 KB，对既有基线增加约 1.2%；八个受测页面均通过原有 5% 门槛，未调整基线。完整互动所需的独立组件仍会在客户端加载，此数值不代表整站所有资源总量。

验证包括 1074 项测试、正式静态构建、客户端数据与硬编码审计，Chrome 320/390/700/900/1440 宽度，WebKit 手机布局，以及以下行为：

- 三态、致意、暂停、暂停且离屏后的尺寸重绘。
- 演示操作、场景及材料交接、冷启动时延迟工作台组件加载。
- 快捷键、场景草稿、跨模式修改历史任务、三条历史上限。
- 生成时输入保护、连接失败、刷新、限流和停止。
- 后台导航隐藏和排序、首页重排后的滚动高亮。

浏览器模型请求以受控接口响应检查交互及请求格式；并未据此宣称逐个实测所有线上模型的回答质量。
