# 界面与扩展约定

公开站采用暖米白背景、鼠尾草绿主色、浅沙色与淡紫辅助面板。系统字体、圆角、间距和色彩由 `app/globals.css` 的语义变量控制；`app/styles/surfaces.css` 提供入口卡片、学习卡片、首页工作台等表面样式。新页面应复用 `PageHeader`、`Section`、`Button` 和 `ToolCard`，避免各页面独立定义配色。

公开页面位于 `app/(public)/`，此路由分组不改变浏览器地址。`app/(public)/layout.tsx` 集中管理公开导航、页脚、助手与统计。后台位于 `app/admin/`，拥有独立布局和样式，不加载公开站的新手引导或统计采集。

新增后台分区时，在 `components/admin/admin-shell.tsx` 的分区定义中登记入口，新增面板组件，并在 `lib/admin/api.ts` 注册服务端鉴权路由。后台不开放账号注册，管理路由仅对已登录的所有者开放。

## 浏览统计

- `/api/collect` 接收公开页面浏览与白名单操作事件。操作事件不重复计为页面浏览。
- `page_views` 保存每天每个路径的浏览量；`page_view_minutes` 保存每分钟每个路径的浏览量，最多保留最近两天。不存在访客 ID、IP、UA 或指纹列。
- 日统计按北京时间划分日期。历史旧版日统计曾采用 UTC；该部分已聚合数据无法重新划分时区，保留原始日期记录。
- `/api/admin/analytics?period=7d` 仅对所有者开放，支持 `today`、`7d`、`30d`、`90d`、`6m`、`12m`。月视图按日历月份汇总，包含当月截至今天的数据。
- 仪表盘每十秒读取一次最新统计，隐藏标签页时暂停请求，回到页面后立即刷新。实时指标为近五分钟和近一小时的页面浏览次数，不代表独立人数。
- 离线缓存排除所有 API、后台页面和 RSC 响应；管理端 GET 请求设置 `no-store`，旧 Service Worker 激活新版时清除旧缓存。
- 分钟表通过幂等的 `CREATE TABLE IF NOT EXISTS` 创建，已有 D1 数据库无需删除或重建。

## 管理账号

账号只在数据库保存密码哈希。可通过后台「账号安全」修改密码，也可以使用 `scripts/set-owner.mjs` 配置唯一所有者；凭据由环境变量传入，脚本不包含任何实际密码。修改所有者时会撤销旧登录会话。

## 设计参考

导航层级与固定操作位置参考 [Linear 的界面整理](https://linear.app/now/behind-the-latest-design-refresh)。配色、首页与后台视觉是本项目的独立设计。

## 搜索与图文学习

顶栏使用普通搜索输入框，结果通过 Portal 锚定在输入框下方，不创建整页蒙层或模糊遮罩。支持方向键、回车、Esc、斜杠和 Ctrl/Cmd+K。索引只在首次使用时读取，并在当前会话缓存；网络请求绕开旧离线缓存，避免标题更新后仍返回旧索引。

`data/lesson-summaries.ts` 维护各教程的短标题、产出、操作和验收清单。每篇短版必须覆盖原有全部步骤，细节保留为可展开说明。添加教程时同时维护短版，`lesson-summaries.test.ts` 会检查覆盖情况。图解六要素使用原生 HTML，文字可选中并可被读屏识别。

`components/learning/quick-practice.tsx` 提供日常任务模板，输入的材料只在当前页面内存中整理，不发送到模型或后台。验收清单只在本地保存勾选状态，不保存练习材料。

教学插图使用内置 ImageGen 生成，最终资产和提示词记录见 `public/illustrations/README.md`。网页引用 WebP，每张插图约几十 KB，避免让图文教学变成大图片下载。
