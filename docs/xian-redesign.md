# 弦域 XIAN · 整站设计重构

2026-10-29，按站主的新要求重构品牌与展示层。名字、字标、浏览器图标、首页、教师首页、导航、页脚、共享内页标题及后台视觉统一为弦域 XIAN。现有网址、鉴权、模型凭据、官方资讯来源、编辑资料及学习夹保留。

## 设计参考

- [MotionSites](https://motionsites.ai/)：整页构图、单一主视觉、太空叙事。
- [React Bits](https://reactbits.dev/)：鼠标响应和可暂停的程序化视觉。
- [Uiverse](https://uiverse.io/)：按钮、输入和边缘反馈。
- [Aceternity UI](https://ui.aceternity.com/components)：交互卡片、页签和信息层次。

这些是设计研究参考，未复制付费模板或第三方组件源码。需求通过用户指定的 Prompt Perfect 整理，未保存提示词到用户库。

## 页面与交互

首页围绕探索工具、任务终端、学习路线、实践档案及官方动态组织。支持分类、搜索、收藏、并排对比、任务类型切换、示例填入、真实流式模型回答、停止、复制、模型连接刷新，以及路线和案例展开。单个工具不直接进入对比。

任务终端复用 `/api/assistant/models` 和 `/api/assistant/chat`，使用 practice 模式，不把一般请求限制为站内检索。调用失败、限流和停止会明确显示。示例材料标为示例，不把示例当作模型真实输出。原有初学者引导保留在明确选择的 `/start/` 和 `?tour=1`，不再遮住首次访问的首页。

首页继续使用 PageRegions，保留后台隐藏、排序和自定义内容能力。内置新区域 workspace、final 注册到服务端校验；栏目开关仍约束首页入口。教师端增加备课、课堂、评价阶段切换、步骤展开、课题编辑和实际复制反馈。

## 性能与兼容

主视觉为原生 Canvas 加 SVG 静态回退；不引入视频、Three.js、外部字体或额外动画依赖。离屏和后台暂停，遵循减少动态效果设置，暂停时改变尺寸仍重绘。回答解析器继续按需加载，后台编辑器和完整资料不进入公共共享包。品牌素材由原生 SVG 及其 PNG 导出构成。

这次是显式要求的整站重构，性能基线按新页面结构重新采集，保留后续 5% 回归门禁。重构后首页 gzip 首屏约 194 KB，与上版约 193 KB 接近；教师首页新增交互工作台，约 173 KB。旧基线在任务 QA 目录留存，客户端数据审计通过。具体数值以 perf-baseline.json 和最终构建为准。

验证：现有 1074 项测试；Chrome 的 320/390/700/900/1440 宽度；首页交互、真实接口请求格式、复制结果、搜索、原栏目导航、教师和后台页面；WebKit 窄屏、暂停后重绘、失败/重试/停止路径另行检查。
