# 模型与 Agent 进阶内容

入口 `/learn/advanced/`，顺序路径 `/paths/model-to-agent/`。知识库导航、教程页和站内搜索都有入口。

六个练习围绕模型选型、结构化交接、知识检索、Agent 工具任务、失败定位和结果/消耗验收。新增概念包含模型路由、结构化输出、工作流、工具调用、记忆、评估和人工审批；原有 Agent 与提示注入条目已按新路线补充。框架参考提供 Dify、n8n、LangGraph 的场景、起点和当前官方说明，并链接到各自工具档案；框架的流程能力与基础模型知识能力分别说明。

## 内容如何维护

- `data/advanced-guides.ts`：教程、可填变量模板、常见错误与验收标准。长产出说明保留在数据中，列表使用短摘要。
- `data/advanced-concepts.ts`：概念与官方参考，合入原知识库和术语表；避免重复已有 ID。
- `data/advanced-learning.ts`：阶段顺序、关联材料和框架入口。新增引用须有真实站内路由。
- `data/guide-visuals.ts` 与 `data/case-visuals.ts`：场景流程图。图中节点应与原教程、案例的操作及验收相符，不额外虚构效率或模型成绩。
- `data/concept-maps.ts`：工作／教学两个场景的概念图解。

`AgentLab` 是虚构材料的本地交互走读。它展示判断、调用提议与真实返回的区别，以及缺项、工具失败、夹带指令时的处理。它不调用模型或执行外部操作，不能作为真实 Agent 测试成绩。`lib/learning/agent-walkthrough.ts` 保存示例和规则；修改场景时同步核对材料、草稿和暂停条件。

教程正文优先显示可操作步骤，长输入示例、深入解释与参考可展开。周报、分层任务单、表格清洗的案例增加了对应图解。新增校内通知、报修分类、会议行动项三个演示案例，入口也放在进阶页。案例长提示词按需展开。打印前展开正文说明，打印后恢复浏览状态。进度与练习检查沿用当前浏览器本地保存方式。

验证入口：`lib/__tests__/advanced-learning.test.ts` 检查课程引用、提示词变量和走读的关键失败路径；原有全站数据、教学质量、搜索和性能检查继续适用。内容变化后执行生产构建，并检查手机端与交互。
