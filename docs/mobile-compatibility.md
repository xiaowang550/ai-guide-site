# 手机与浏览器适配

2026-10-13：知芽AI 的大众端、教师端、管理后台沿用同一品牌与配色，分别提供适合触摸操作的导航结构。

## 操作与布局

- 大众端提供首页、教程、工具、资讯和学习夹底部入口，随后台栏目配置隐藏禁用入口。案例、知识库、反馈和子栏目从顶部菜单进入，学校资源保持登录保护。
- 教师端底部提供总览、课程、教案、规范和答疑。手机上隐藏重复的顶部课程导航；新增学校自定义栏目仍保留入口。管理员预览链接继续带预览参数。
- 管理后台手机分区使用菜单面板，同一份分区数据驱动桌面侧栏与手机菜单。操作记录表格可内部左右滚动，不撑宽整页。
- 菜单通过原生 dialog 提供焦点限制、背景不可交互、Escape 关闭和焦点恢复；触发按钮主动获取焦点，兼容 Safari 的按钮轻触行为。
- 适配安全区域、横屏、动态地址栏与可见视口变化，保留双指缩放。手机输入字号至少 16px；键盘出现时底部导航和小芽让出空间。
- 小芽提前预留底部导航高度，在视口变化后的动画帧重新定位。Safari 轻触后的兼容鼠标点击不再重复开关聊天；真实鼠标和键盘操作仍可使用。
- 手机导航按需加载；首页和后台专用样式分别放在对应页面，避免教师端下载无关样式。原性能基线及 5% 阈值保持不变。

## 后续 App 基础

PWA 清单提供稳定应用标识、横竖屏支持和 maskable 图标；补充 Apple 主屏幕元数据。菜单中提供安装入口或浏览器操作说明，不主动弹出安装窗口。

Service Worker v7 补齐首页、离线页和已加载的公开脚本、样式、图片。API、管理页面、教师页面、学校登录、预览页面、RSC 和 no-store 请求均不进入离线缓存；带 private/no-store 的响应也不保存。仅清理本站旧版本缓存。

更新等待使用者点击“刷新更新”，不自动打断未提交的表单。已缓存的公开页面可离线阅读；登录、提交反馈、实时资讯和 AI 推理需要网络。浏览器可能清理缓存，离线能力不作为永久保存或内容备份。

这些是网页与 PWA 的基础，后续原生 App 的打包、签名、系统权限、推送和商店发布需要单独完成。

## 验证

- 实际运行 Chrome、Edge、Firefox 和 WebKit 引擎，384 项检查通过。
- 检查 320、360、375、390、414、430、768、812、1440px 宽度，包含 812 × 375 横屏。
- 检查主要公开页面、工具与教程详情、学习路径、反馈、两个登录页、登录后的六个学校页面与后台主要分区。
- 实际触摸事件验证菜单、搜索、小芽、后台分区、学校课程入口；检查菜单焦点恢复、搜索输入字号、弹窗边界、小芽与底栏不重叠、整页不横向溢出。
- Chromium 断网验证缓存首页、教程与菜单；检查缓存中没有 API、后台或学校页面。
- 单元测试模拟 Android 布局视口缩小、iOS 可见视口与滚动偏移、双指缩放；安全区域使用标准 env(safe-area-inset-*)。
- 构建、类型检查、代码检查、客户端数据审计、规模文案审计及原性能基线通过。

以上为浏览器引擎与视口模拟验证，未连接安卓或 iPhone 真机，不代表逐台机型或所有旧版浏览器实测。原生 App 上架前仍需真机验收输入法、系统字体、刘海屏、浏览器工具栏和安装体验。
