# 页面内容管理

后台「大众 / 学生端」和学校内容管理现在包含「页面内容管理」。选择页面后，可以编辑内容区块及其卡片、步骤、问答、链接；支持新增、复制、修改、排序、隐藏、删除、恢复和搜索。

首页学习入口、任务卡片，工具页的榜单说明、选工具步骤和使用提示，以及教程分类、帮助入口、案例阅读说明提供原始内容，编辑后可恢复。工具列表、对话、资讯筛选等功能区保留原组件，允许隐藏、排序、恢复，并可在旁边添加说明区块。工具资料和资讯条目继续通过各自的编辑器管理。

数据保存在 `site_modules.data.regions`，沿用模块的乐观版本锁、认证、同源检查和审计记录。保存后通过既有配置同步机制更新已打开的页面。普通浏览器只接收可见内容；隐藏的内置区块保留无正文的标识，避免默认内容重新出现。删除是可恢复的，内置功能区不能被普通卡片替换。

公开导航、应用快捷入口不再包含内容复核。旧 `/freshness/` 地址跳到 `/admin/?tab=review`；数据经认证接口读取，不在静态后台 HTML、公开配置或离线缓存中提供。后台复核概览以已发布工具的人工发布时间为依据，自动同步资讯不会刷新该日期。此前复核任务与处理记录继续保留。

展示器按需加载，后台编辑器和区块注册表不进入公开客户端。验证包括 HTTP 权限、隐藏字段、版本冲突、非法内容和浏览器中的子项编辑、同步、删除恢复、原功能可用性与手机布局。
