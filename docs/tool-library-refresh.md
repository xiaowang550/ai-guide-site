# 工具库视觉更新（2026-10-12）

- `docs/tool-icon-sources.json` 记录各图标的官方页面、素材地址、原文件 SHA256 和核对日期。图形颜色、比例与内容保持原样，位图仅归一化格式和显示分辨率；素材自托管。
- Gemma 使用官方模型页的 Google DeepMind 标识；GitHub Copilot 使用官方产品网站的 GitHub 标识，避开已弃用的旧独立 Logo。来源记录不是授权证明；页脚保留第三方指南与品牌归属声明。
- 前台评分等比例换算为十分制（原始编辑分 × 2），维度权重、排序、筛选逻辑和依据不变。筛选门槛、详情、图表刻度、数值表与方法说明统一展示口径。
- 首页“本周推荐”混合工具、教程和案例。“换一换”只切换内容，不虚构用户评分。星标是能力综合分；火焰是关联模型系列的公开 Token 调用热度，不代表用户人数或模型效果。
- 热度使用已有加密 OpenRouter Key，固定请求官方 Data API，统计近七个完整 UTC 日。缓存六小时、失败冷却十五分钟、数据库锁避免并发刷新；不调用推理，不公开 Key 或私人用量。访问时更新，超过七天的数据停止标为热门。
- 上游不可用时保留有效快照；页面显示来源与日期，按 CC BY 4.0 署名。资料：[OpenRouter Data API](https://openrouter.ai/docs/cookbook/administration/data-api)、[公开榜单](https://openrouter.ai/rankings)。

## 加载体积

新界面使用页面专属 CSS、紧凑工具投影、服务端推荐卡片。榜单请求代码在挂载后加载。客户端数据审计确认完整工具与场景数据仍仅由决策器加载，没有进入公共包。

上个线上版本到本次功能版本：首页 gzip 约 185.8 → 188.4 KB（+1.4%），工具库 196.4 → 198.9 KB（+1.3%），决策器 254.4 → 254.8 KB（+0.2%）。增量来自新增推荐、热度和评分界面。完成浏览器验证后记录本次功能版本的性能基线，后续仍执行原有 5% 回归门禁。
