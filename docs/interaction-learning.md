# 学习与浏览交互

本轮参考 [NN/g 渐进展示](https://www.nngroup.com/articles/progressive-disclosure/) 与 [筛选意图研究](https://www.nngroup.com/articles/applying-filters/)，将常用操作保留在前台，把细项留给可展开区域。保持当前柔和的视觉体系和访客免登录原则。

## 学习夹

入口 `/saved/`，桌面顶栏、导航子菜单与页脚可进入。工具、教程、概念、案例和路径详情提供“加入学习夹”；案例列表也能收藏，但不会把列表里的全部案例计入最近浏览。

收藏最多 100 条，最近浏览最多 8 条，在当前浏览器 `localStorage` 保存；不向管理数据库或第三方发送内容。支持移除后的撤销、按内容类型查看和清除最近记录。存储拒绝时明确提示失败。关闭的栏目在学习夹中隐藏，数据保留，恢复开放后重新显示。

学习夹是内置栏目 `saved`，可在后台“前台与模块”开关。迁移会补充这个栏目，不覆盖已存在的开关或内容。管理员预览不会记录最近浏览。新页面使用 noindex，避免把个人入口作为资料页索引。

## 找内容

案例库按任务主题、行业和关键词交叉筛选，只传卡片需要的元数据，完整提示词留在详情页。条件体现在地址栏，重新打开地址或返回时恢复。任务主题是文本及工具分类的宽泛导航，允许同一案例出现在多个主题。

搜索先限定内容类型，再截断结果；大量工具匹配不会挤掉教程或案例。类型和查询可由链接恢复，浏览器返回同步页面控件。手机搜索页不会自动抢焦点弹出键盘。全站搜索继续按需加载。

手机工具筛选使用原生 dialog，焦点限制在面板内，支持 Escape、关闭按钮、点击遮罩和底部“查看 X 个工具”。关闭后恢复背景滚动与按钮焦点；切换到桌面尺寸也会关闭。无效 URL 条件忽略，不导致全空列表。当前过滤条件可以逐项移除。

## 复制反馈

`lib/copy-text.ts` 统一复制结果。只有系统剪贴板或 fallback 确认成功才显示“已复制”；失败显示手动复制提示。fallback 恢复原有焦点与选择范围，提示计时器在卸载时清理。

验证包含学习夹存储拒绝、去重、容量与非法链接，搜索分类截断，案例跨主题过滤；浏览器验证收藏撤销、最近浏览、链接状态、手机面板焦点/关闭、复制失败与成功及多种屏幕宽度。
