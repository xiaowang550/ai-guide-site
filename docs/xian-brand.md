# 弦域 XIAN

以两条交汇的椭圆轨道构成符号：远看是 X，近看是一组可延伸的运动路径。中心点表示当前任务，轨道上的亮点表示正在抵达的下一步。

| 用途 | 文件 |
| --- | --- |
| 深色页面中的横向品牌 | `/brand/xian/logo.svg` |
| 独立符号、界面角标 | `/brand/xian/mark.svg` |
| 浏览器图标与方形入口 | `/brand/xian/favicon.svg` |

主色为电光青柠 `#d7ff64`，底色为墨黑 `#080b0a`，字色为暖白 `#f4f5ed`。横向标志和独立符号使用透明底，供深色界面使用；图标带墨黑底。

英文 XIAN 使用几何路径，不依赖字体文件。中文采用设备可用的无衬线中文字体。符号四周至少留出其宽度八分之一的空白；小尺寸优先使用独立符号，避免压缩整条字标。

品牌的轨道可延伸为网页中的进度、节点、路径与悬停反馈。动效宜以缓慢转动、节点发光或短距离位移为主，保留静止状态下的辨识度，并响应减少动态效果的系统设置。
