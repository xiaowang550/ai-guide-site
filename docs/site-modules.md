# 后台管理前台模块

访客无需本站账号。`/settings/` 不再提供公开页面；设置进入 `/admin/` 的“站点设置”。外部 AI 工具的账号、部署和收费由各工具提供方决定。

## 添加与开关

进入“前台与模块”，现有栏目使用小开关开启或关闭。关闭后前台导航和搜索隐藏相应入口，单独访问关闭的栏目会返回 404。关闭知识库时，它下属的进阶入口也会关闭。

“新建模块”支持内容卡片、操作步骤、问答和资料链接。填写标题、简介与内容项，选择首页展示、导航入口和排序。未勾选“公开”时保存为草稿，只能在管理员预览中查看。勾选公开并保存后，无需重新构建，访客刷新即可看到；已打开且可见的页面每 5 秒同步。暂时关闭保留内容，归档停止公开并保留数据库记录。

新模块单独访问地址为 `/modules/?id=模块编号`。它支持安全文本和站内/HTTPS 资料链接；不把输入的 HTML、JavaScript 作为网页执行。新的业务交互需要代码构建。

右侧嵌入前台预览，眼睛按钮切换到相应栏目。预览中的小开关可直接改变公开状态。管理员预览可以看见关闭的内容，标识为私人预览；只有服务端核验 owner 会话后才返回草稿。预览请求、API 和管理页面不进入 Service Worker 缓存。

配置保存在 `site_modules`、`site_features` 与 `site_layout`，首次请求自动建立表并初始化内置栏目。变更具有版本冲突检查，记录到 `audit_log`。写接口需要 owner 会话与同源 Origin，公开 `/api/site` 排除未公开的自定义内容。

## DIY 导航与首页布局

默认主导航为：首页 → 教程 → 案例 → 工具库 → 知识库 → AI 资讯。学校专区仍保留在次级入口与首页对应区域，也可在 DIY 面板勾选成为主导航。桌面导航、手机菜单与页脚共享顺序；手机顶栏另保留快捷返回首页按钮。入口多于六项时，桌面将后续入口收进「更多」，避免挤压搜索。

“前台与模块”顶部的 DIY 面板支持鼠标、触屏拖动手柄，也提供上下移动按钮和显示开关。导航与首页顺序独立保存；首页欢迎区、内容数量、学习入口、推荐工具、学习路径、学校服务、资讯及新建首页模块均可换位置。模块内部内容项也可上移、下移。

调整中的布局仅同步到认证管理员的嵌入预览，支持桌面与手机视图；点击“保存布局”后立即保存到服务器，同浏览器的已打开页面收到同步通知，其他可见页面最多约五秒读取更新。无需重新构建或刷新。恢复默认只恢复布局，不修改栏目开关、模块正文或模型 Key。仅隐藏入口不关闭相应内容，真正关闭栏目仍使用下面的栏目开关。

布局 API 为 `PATCH /api/admin/layout`，要求 owner 会话、同源 Origin 与当前 `version`；验证候选 ID、重复项、数组长度，使用原子版本条件更新防止覆盖其他编辑页面。首页入口可以移动但需保留。公开配置过滤草稿与归档模块的布局 ID；初次加入布局表时保留原栏目和全站设置。

## Codex 功能构建

“Codex 功能构建”保存功能名称与需求，支持复制到 Codex。运行本地 `npm run admin:dev` 时，它会检测本机 Codex CLI 与登录状态；已登录可点击“生成代码草稿”。可用状态不代表某个任务已经成功执行，只有实际完成后才显示“草稿已完成”。

执行器 `scripts/codex-bridge.mjs` 使用 `codex exec --sandbox workspace-write --json`，通过 stdin 传需求，使用本机已有 CLI 登录。只允许一个活动任务。副本位于 `.data/codex-jobs/任务编号/workspace-随机编号`；不复制 `.env`、数据库、Git、凭据目录、构建目录或符号链接。主项目不自动应用草稿。运行结果和源码差异在后台查看，代码检查与构建发布仍是后续步骤。超时、执行失败或执行器重启会明确显示未完成。

官方方式参考 [非交互运行文档](https://developers.openai.com/codex/noninteractive/)。`CODEX_CLI_PATH` 可指定 CLI 的绝对文件路径，否则从本机 Codex 安装目录发现。执行器未找到或未登录时仍可保存、复制需求，不显示虚假的执行成功状态。

Cloudflare Pages 运行模块管理 API 与栏目门禁，使用现有 D1 绑定。该运行环境不直接执行本机 CLI，因此线上构建入口会显示执行器尚未接入；本地登录或密钥不会传到云端。仅静态文件服务器没有这些动态 API，需要使用本地后台服务器或包含 Functions 的部署。
